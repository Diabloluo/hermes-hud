# Roadmap

> Roadmap items are exploratory and do not represent committed delivery dates.

## Now

- Linux real-machine compatibility verification (community testing welcome)
- More health rules (e.g. model cost anomaly, session growth, disk WAL growth)
- Dashboard UX polish: density options, dark/light follow, keyboard shortcuts

## Next

- One-command installer (`curl ... | bash` style) for the plugin + alert helper
- More notification channels (Discord, ntfy, email) for the alert helper
- Tool-level start/end events (precise tool lifecycle, beyond message-inferred calls)
- Windows compatibility improvements (process/drive detection)

## Exploring

- Dashboard UX: plugin slot for custom panels, theme presets
- Community-driven refinements from Issues / Discussions
- Billing sync with provider dashboards (actual cost source)
- I18n for the HUD UI itself (beyond the current Chinese-first UI)
