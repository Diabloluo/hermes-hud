# Desktop Alpha — 90-Day Market Validation

**ZERO outbound product telemetry.** Hermes HUD will never add in-app
telemetry to count installs. Market signals come only from public /
platform-side data.

## Signals (public / platform-side only)

- GitHub Release DMG `download_count`
- GitHub stars
- unique external issues
- Discussions participation
- external PRs
- repeat contributors
- feature requests

## Special signal: multi-agent interest

Explicitly record requests for **Claude Code · Codex · OpenAI Agents ·
LangGraph · other collectors**. Repeated requests for ≥ 1 non-Hermes agent
collector is the strongest indicator for evolving from "Hermes HUD" toward
a multi-agent **Observer Core** observability platform.

## Success thresholds (experimental, not commercial commitments)

| Level | Threshold |
|---|---|
| **Minimum signal** | ≥ 25 Desktop downloads · ≥ 5 external users with meaningful interaction · ≥ 3 substantive Issue/Discussion threads |
| **Strong signal** | ≥ 100 Desktop downloads · ≥ 15 meaningful external users · ≥ 5 feature/compatibility requests |
| **Platform signal** | repeated requests for ≥ 1 non-Hermes agent collector |

Review cadence: at 30 / 60 / 90 days after public Desktop Alpha release.

No in-app telemetry is added under any circumstance.
